# NovaFlow — Modern SaaS Landing Page

A responsive business landing page built with **HTML5**, **Tailwind CSS (CDN)**, and **Vanilla JavaScript**.

## 🚀 Features

- **Responsive Navigation**: Sticky header with blur effect and mobile drawer menu.
- **Hero Section**: High-converting title, gradient badges, trust indicators, and visual pipeline mockup.
- **Product Features Grid**: 6 feature cards with hover states and iconography.
- **Workflow Steps**: 3-step timeline illustrating how the product works.
- **Metrics & Social Proof**: Live statistics counter and client company logos.
- **Interactive Pricing Switcher**: Monthly vs. Annual toggle with dynamic discounted pricing.
- **Customer Testimonials**: Social proof cards with ratings and reviewer titles.
- **FAQ Accordion**: Interactive expand/collapse accordion.
- **Lead Capture CTA & Modal**: Email capture form with animated toast notifications and simulated video modal.
